# 📱 Mobile Sales Dashboard

## 📋 Overview
Interactive Power BI report providing comprehensive smartphone sales performance analysis across multiple cities and brands. Visualizes key metrics including total sales, transactions, average revenue, and customer ratings.

## 🎯 Purpose
Monitor and evaluate mobile sales performance across regions, brands, and models. Track sales trends, assess customer satisfaction, and analyze payment method preferences to support strategic business decisions.

## 🛠 Tech Stack
- *📊 Power BI Desktop* - Data visualization and dashboard creation
- *🧩 Power Query* - Data extraction, transformation, and loading
- *🧠 DAX* - KPIs, measures, and calculations
- *🧱 Data Modeling* - Relationships between brand, city, transaction, and payment tables

## 📊 Data Source
Source: Internal sales and customer transaction databases

Data Includes:
- Sales revenue and transaction metrics
- Customer ratings (1–5 scale)
- Brand, city, and model distribution
- Payment methods (UPI, Credit Card,Debit Card, Cash)
- Monthly sales trends

## ✨ Features
- Interactive city-wise sales map
- Monthly sales quantity and transaction trends
- Payment method breakdown visualization
- Customer rating analysis
